A COMPUTATIONAL APPROACH FOR PERTURBATION-INDUCED EMT TRANSITIONS, by Daniel Ramirez, David A. Kessler, Herbert Levine, and Mingyang Lu.


This repository includes input topologies and analysis scripts to simulate a 26- and 72-node EMT GRN and analyze each with respect to EMT-driving perturbations. 

All RACIPE simulations and analysis for the 26-node GRN is included in the R script emt_26node_2025.R, with visualizations in emt_26node_viz_2025.R

The 72-node network RACIPE simulations are derived from the python implementation of RACIPE: https://github.com/arkatebi/cellcycle. The preprocessing steps for this GRN are included in the .ipynb notebook Bistability_Analysis_72node_5k_200ic_2025.ipynb.
